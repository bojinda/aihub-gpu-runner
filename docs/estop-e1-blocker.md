# Historical mixed-version blocker — superseded

The operator approved a coordinated stop and complete upgrade. Obsolete writers must be absent before activation and cannot be relaunched by approved launchers. The same-version revision/generation checks resolve the current stale-writer requirement without tombstones, special directory permissions or a successor journal.

The prior blocker and reproducer remain in Git history and private evidence; they are not an E1 acceptance requirement for a deliberately excluded mixed-version deployment. See [current E1 design](estop-e1.md).
